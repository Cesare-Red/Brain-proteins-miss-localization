# Varianti con localizzazione misurata (facoltative)

Lo 01 aggiunge ogni file `*.csv` di questa cartella alle varianti di Lacoste et al., che scarica da solo.
Formato:

```
gene,variante,mislocalizzata
SOD1,A4V,1
```

`variante` nella forma p. abbreviata (A4V); `mislocalizzata` = 1 se lo studio misura uno spostamento, 0 se no.
Vuota va bene.
